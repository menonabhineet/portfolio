# Abhineet Menon — Portfolio

> **Data Engineer & Full-Stack AI Developer**  
> MS in Computer Science @ University of Illinois Chicago (4.0 GPA)

Personal portfolio website showcasing experience in enterprise Data Engineering (Snowflake, ETL pipelines, Azure ADF), Full-Stack Systems, and AI/RAG architectures.

---

### Highlights & Features

- **Interactive Binary Matrix Canvas**: Custom HTML5 Canvas engine with real-time cursor physics.
- **Dual Project View**: Switch between a 3D Perspective Carousel and a Responsive Grid.
- **Typo-Tolerant Fuzzy Search & Command Palette (`Ctrl+K`)**: Rapid keyword search across projects, skills, and actions.
- **In-App Resume PDF Viewer**: Preview and download official resume directly within the app.
- **Evidence-Based Skill Linking**: Cross-reference technologies directly to real-world project implementations.

---

### Built With

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19 & TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
